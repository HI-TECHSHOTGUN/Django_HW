# Интернет магазин
## Описание
Создание проекта интернет магазина используя bootstrap и django

## Установка
1. **Клонируйте репозиторий**
        [клик](https://github.com/HI-TECHSHOTGUN/Django_HW.git)
## Зависимости и виртуальное окружение:
1. **Виртуальное окружение** (в данном случае Poetry) установки не требует и идёт в комплекте при клонировании репозитория.
2. **Зависимости** также можно посмотреть в этом файле [клик](pyproject.toml)

## Функционал проекта:
Запуск и работа веб приложения которое выводит главную страницу и при нажатии на вкладку контакты совершает переход на следующую страницу

### Запуск проекта:
Для запуска проекта выполните
    ```
    python manage.py runserver
    ```

#### Нововведения:
Создан основной функционал проекта с рабочим сервером на основе фреймворка django а также функционал для взаимодействия URL адресов и соответственно сверстаны главная страница и страница контактов

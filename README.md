# Интернет магазин
## Описание
Создание проекта интернет магазина используя bootstrap и django, проект приобрел вид интернет магазина, ориентированного на сбыт
растительных продуктов питания

## Установка
1. **Клонируйте репозиторий**
        [клик](https://github.com/HI-TECHSHOTGUN/Django_HW.git)
## Зависимости и виртуальное окружение:
1. **Виртуальное окружение** (в данном случае Poetry) установки не требует и идёт в комплекте при клонировании репозитория.
2. **Зависимости** также можно посмотреть в этом файле [клик](pyproject.toml)

## Функционал проекта:
Запуск и работа веб приложения которое выводит главную страницу и при нажатии на вкладку контакты совершает переход на следующую страницу,
улучшен предыдущий функционал, также изменен дизайн шаблонов.
При запуске сайт отображает карточки товаров, при нажатии кнопки подробнее происходит переход
на следующую страницу на которой можно подробнее ознакомиться с товаром и вернуться назад также есть кликабельное меню
с возможностью выхода на главную страницу, также осталась и функциональная кнопка контакты с сопутствующей страницей перенесенная на новый стиль приложения

### Запуск проекта:
Для запуска проекта выполните
    ```
    python manage.py runserver
    ```

#### Нововведения:
Осуществлена работа с базой данных и подтягивание данных из них, улучшен дизайн проекта, а также улучшена его структуризация
(меньше повторяющегося кода)
